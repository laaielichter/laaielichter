# Hi, I'm Roel 👋

I build **local, open-source tools that make AI coding agents better at real work**: games, data and memory.
Everything runs on your own machine.

## ⭐ Flagship

### [ReversePort](https://github.com/laaielichter/Reverseport): reverse engineer anything, port it anywhere

Let your agent read Godot `.pck`, Unity IL2CPP and asset bundles, .NET and native builds, diff builds,
and port games between Godot, Unity, Unreal and three.js, with proof for every claim.

`npx reverseport setup`

<img src="https://raw.githubusercontent.com/laaielichter/Reverseport/main/docs/assets/demo.gif" width="560" alt="ReversePort porting Godot's 2D platformer demo to Unity">

## 🎮 For game and 3D agents

| Tool | Purpose |
|---|---|
| [**Godotwright**](https://github.com/laaielichter/Godotwright) | Checks the Godot 4 code your agent writes: offline API, review, headless checks, Godot 3 to 4 migration |
| [**Threesmith**](https://github.com/laaielichter/Threesmith) | The same for three.js: version-pinned review, headless page checks, 3D models from code |
